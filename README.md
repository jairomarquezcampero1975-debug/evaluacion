# TecnoStore - Sistema Web de Venta

Proyecto universitario con PHP, MySQL, HTML, CSS, JavaScript, Bootstrap, Git y GitHub.

## Instalacion rapida
1. Copiar la carpeta `evaluacion_corregido` dentro de `C:\xampp\htdocs\`.
2. Abrir XAMPP y activar Apache y MySQL.
3. Entrar a phpMyAdmin e importar `database/sistema_ventas.sql`.
4. Abrir `http://localhost/evaluacion_corregido/index.php`.
